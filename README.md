# nudo — laboratorio de creación editorial

Sitio de una página para nudo. HTML, CSS y JS sin dependencias ni build.

- `web/index.html` — contenido
- `web/styles.css` — estilos (paleta y tipografías del kit de marca)
- `web/main.js` — interacciones: logo de hilo en WebGL, círculos de palabras, hilos separadores, hilo del proceso, galería de proyectos
- `web/assets/` — imágenes optimizadas, videos, fuentes y el logo embebido (`js/logo-data.js`)

## Ver en local

```bash
cd web && python3 -m http.server 8765
```

También funciona abriendo `web/index.html` directamente.
